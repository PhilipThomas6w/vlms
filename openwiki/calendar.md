# Calendar (FR-022)

Requirement: `docs/requirements/functional.md` FR-022. The Church's liturgical calendar (New Calendar, from the Greek Orthodox Archdiocese of America's ICS feed) alongside each chapter's events (the days it meets). Registers per class per event: [attendance.md](attendance.md).

## Data

- `Vlms.Domain/ChapterEvent.cs` (`IChapterOwned`, top-level): date, name, optional start/end time and place, `Kind` (`ChapterEventKind`: Class, Excursion, Service, ParishMeeting; `IsVarangians()` = Class or Excursion, `Label()`), `SeriesId` (the first event's id when created as a repeat). Unique per chapter per date for Varangians kinds only (filtered index `kind IN (1, 2)`). Chapter filter arm only; anyone working in the chapter reads them. Migration `AddEventKindsAndSeries` (existing events become classes).
- `LiturgicalDay.cs` (national, key = date): title, `LiturgicalFast`, saints; `LiturgicalReading` (heading, reference, text, order). Listed as national in `ChapterSeparationTests`.
- `CalendarFeedToken.cs` (per person per chapter, not chapter-owned, like `ActiveChapterChoice`): SHA-256 hash of the subscribe link's secret.
- `CalendarViewChoice.cs` (per person, key `UserId`, migration `AddCalendarViewChoice`): the `CalendarView` (List, Grid) last chosen on `/calendar`.
- `AddedSaint.cs` (national, migration `AddAddedSaints`): a British or Irish saint kept each year on a `Month` and `Day`; unique per month, day and name. Listed as national in `ChapterSeparationTests`.

## `Calendar/`

- `LiturgicalFeedParser`: unfolds and unescapes the ICS; per VEVENT, the `DTSTART` date, `SUMMARY` without the leading fasting emoji, and the description's paragraphs: "Saints and Feasts:", the fast line (`Fast Free`, `Fast Day (... Allowed)`, `Strict Fast`; none = `LiturgicalFast.None`), and "... Reading(s): reference" plus text until the next reading.
- `LiturgicalCalendarImporter`: system principal only; downloads (`Calendar:LiturgicalFeedUrl`, default the GOARCH feed), parses, and in one transaction replaces every day in the feed's range. Run by `Vlms.Jobs` after the daily sweep, and by `Vlms.Jobs import-calendar`; a failure is logged and sets exit code 1, keeping the days already stored.
- `CalendarService`: `CanRead` (any chapter role in the active chapter); `GetMonthAsync`, `GetUpcomingAsync`, `GetLiturgicalDayAsync`, `GetEventAsync`, `GetViewAsync`/`SetViewAsync` (the caller's own `CalendarViewChoice`); Admin-only `CreateEventAsync(input, EventRepeat?)` (one event per date of `RepeatDates`: weekly, monthly on the nth weekday, yearly; up to `MaxRepeatYears` = 5; the whole series refused if any date has a class or excursion), `UpdateEventAsync` (no date or kind change once a register exists), `DeleteEventAsync(id, andLaterInSeries)` (returns `EventRemoval`; keeps dates with registers; refuses this event if it has one). One class or excursion a day; parish events unlimited.
- `AddedSaintService` (National Administrator with MFA, checked in the service): `ListAsync`, `AddAsync(month, day, name)`, `RemoveAsync`, `PreviewImportAsync(csv)` (RFC 4180 parse, optional header, at most 256 KB and 2,000 rows; per row `SaintImportRow`: error, already added, that date's feed saints this year, `InFeed`), `ImportAsync(SaintToAdd[])` (skips already added and repeats, never removes); `SameName` (case-insensitive, trimmed), `TryParseDate` (D/M or DD/MM). `CalendarService.GetLiturgicalDayAsync` appends the day's added saints, alphabetically, after the feed's, leaving out any `SameName` as a feed saint.
- `CalendarFeedService`: `GetLinkCreatedAtAsync`, `CreateLinkAsync` (returns the secret once), `RemoveLinkAsync` for the caller's active chapter; `BuildFeedAsync(secret)` (no sign-in) finds the hash, checks the owner still belongs to the chapter (`ChapterMembership.ChapterIds`), reads events through a short-lived `CalendarFeedUserContext` for that chapter, and writes iCalendar (UK times as UTC, all-day events without times, escaping, 75-octet folding).

## Web

- `Pages/Calendar/Calendar.razor` (`/calendar`, `RequireChapterMember`, nav "Calendar"): `?month=yyyy-MM`; a List/Grid switch (`aria-pressed`), saved with `SetViewAsync`. List: one row per day, feast, `Ui/FastPill`, events, "Saints and readings" expands per day. Grid: a Monday-first `table`, one button per day (`aria-expanded`), the chosen day's events, feast, saints and readings in `#selected-day` below; under 48rem a cell shows only the number, an event dot (filled for Varangians events, a ring for parish events; the kind also in visually hidden text) and `FastPill Short`; list rows and the selected day show each event's kind as a pill. With no saved choice both views render and CSS shows the list under 48rem, the grid above; the subscribe link panel.
- `Pages/Calendar/EventPage.razor` (`/calendar/events/{id}`, `RequireChapterMember`): event details and kind; for a class, its class registers and the day total, for an excursion its one register (`/attendance/{id}/everyone`), for Teachers and Admins; parish events have none.
- `Pages/Calendar/EditEvent.razor` (`/calendar/events/new`, `/calendar/events/{id}/edit`, `RequireAdmin`): kind radios (locked once a register exists), "Repeats" and "Last date" on new events; on a series date, "Remove this date only" or "Remove this and later dates", each confirmed.
- `Pages/Administration/AddedSaints.razor` (`/administration/saints`, `RequireNationalAdministrator`, nav National "Added saints"): add a saint (day and month selects, name); import a .csv with a preview table (a checkbox per addable row, unticked where the feed already lists the name); the list with a confirmed remove per saint.
- `CalendarFeedEndpoint` (`GET /calendar/feed/{secret}.ics`, anonymous, 404 unless valid, `Cache-Control: private, no-store`).
- Policy `RequireChapterMember` (`Program.cs`): Admin, Teacher, Safeguarding Officer, Parent or Student in the active chapter, plus the MFA rule.
