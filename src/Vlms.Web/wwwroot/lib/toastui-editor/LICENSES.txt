The lesson editor (docs/adr/0013-lesson-suggestions-review-and-history.md decision 6).

toastui-editor.min.js is one bundle (window.toastui.Editor), built on 26/10/2026 with esbuild 0.25.0 from these npm
packages; toastui-editor.css is @toast-ui/editor 3.2.2's dist/toastui-editor.css, unchanged.

- prosemirror-commands 1.7.2, prosemirror-history 1.5.1, prosemirror-inputrules 1.5.1, prosemirror-keymap 1.2.3,
  prosemirror-model 1.25.12, prosemirror-state 1.4.4, prosemirror-transform 1.12.4, prosemirror-view 1.42.8,
  rope-sequence 1.3.4, w3c-keyname 2.2.8, orderedmap 2.1.1: MIT, https://github.com/ProseMirror
